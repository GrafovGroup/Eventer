Status: Direction approved; production vector reconstruction and visual signoff pending.

## Brand
Name: EVENTER
Tagline: EVERYTHING EVENTS.
Never use "One Provider" anywhere.
Positioning: colourful, creative, contemporary and premium enough for corporate procurement.

## Proposed tokens
Navy #07152F; white #FFFFFF; cyan #00C9F4; blue #175CFF; violet #7437F5; magenta #EE24AD; orange #FF7B1A; red #F32638.
Use gradients selectively for icon and accents, not body copy. Meet WCAG contrast.

## Typography
Use licensed or open-source geometric sans with clear uppercase wordmark; site body should be legible and restrained. Test English/French accents and glyphs.

## UI
Wide responsive desktop containers with readable text measure. High-quality distinct event photography. Uppercase nav/CTAs, EN/FR in top bar, sticky mobile actions only when unobtrusive. White, navy and occasional dark feature sections. No overdecorated gradients.
